# Njilo Platform Demo Script (5–7 minutes)

## 1) Public Website (2 minutes)
- Open http://localhost:3000
- Highlight the hero slider, animated stats, and enterprise layout.
- Navigate Services → Service Directory, open a service detail page.
- Visit Media → Publications and Careers → Active Vacancies.
- Submit “Request a Quote” and “Contact Us” forms.

## 2) Intranet Login + Dashboard (1 minute)
- Open http://localhost:3001
- Login with demo credentials (see README/.env).
- Show KPI cards, latest leads, and open tickets.

## 3) CRM + Ops Modules (2 minutes)
- CRM → Leads (show captured public forms).
- CRM → Opportunities (view pipeline stages).
- Fleet Ops → Vehicles, Maintenance Tickets, Fuel Logs.
- Waste Ops → Jobs/Pickups and Compliance Notes.

## 4) CMS → Public Sync (1 minute)
- Intranet CMS → Partners and Testimonials.
- Refresh public home page to show updated carousels and testimonials.

## 5) Admin (30–60 seconds)
- Admin → Users & Roles.
- Audit Log entries created from content updates.
